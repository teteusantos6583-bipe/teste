# Serviço de automação — como colocar no ar (Render, grátis)

1. Crie uma conta em https://github.com e crie um repositório novo. Envie estes arquivos para ele (botão "Add file" > "Upload files").
2. Crie uma conta em https://render.com e clique em **New > Web Service**.
3. Escolha o repositório. Em "Language/Runtime" selecione **Docker**. Plano: **Free**.
4. Clique em **Create Web Service** e espere terminar (alguns minutos).
5. Copie o endereço gerado (ex.: https://servico-automacao.onrender.com).
6. Mande esse endereço no chat do Lovable para conectar ao painel.

Teste rápido: abra o endereço no navegador — deve aparecer {"ok":true}.
Obs.: no plano grátis o serviço "dorme" após inatividade; o primeiro teste pode demorar ~1 minuto.
